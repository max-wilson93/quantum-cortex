# Coherent Phase Cortex

A complex-valued cortical column that classifies through **wave interference**
rather than scalar summation, fed by a **Fourier-optical front-end**, trained by
**local Hebbian updates with no backpropagation**, and held stable by **global
energy homeostasis**.

Formerly "The Quantum-Holographic Cortex". The physics here is classical wave
optics — interference between complex amplitudes, which is Maxwell rather than
Schrödinger — so the quantum framing was retired. See
[What this is not](#what-this-is-not).

> **Every number about this project lives in [`results.md`](results.md)**, which
> is generated by scripts in this repository and records the commit, seed list
> and sample count that produced each table. There are deliberately no accuracy
> figures in this README. If you want to know how well it works, run
> `python bench.py`, or read the file it writes.

## What this is

The model has four parts, and the first one is doing most of the work.

**1. A Fourier-optical front-end** (`fourier_optics.py`). The image goes through
a 2-D FFT, is masked by four oriented bandpass wedges (0°, 45°, 90°, 135°;
radius 1–14), and comes back through an inverse FFT. This is a $4f$ correlator
in software, and it is a good feature extractor: it lifts a plain linear
classifier substantially above the same classifier on raw pixels
(see `results.md`, baselines table).

Because each mask is a **single-sided** angular wedge and a real image has a
Hermitian spectrum, every filtered channel is an **analytic signal**. Its
magnitude is a phase-invariant envelope — which is why taking `np.abs()` works
as a complex-cell energy detector — and its phase is the **local Gabor phase**,
encoding edge position and polarity.

**2. A complex-valued resonator** (`quantum_cortex.py`). Neurons are phasors,
$\Psi = Ae^{i\theta}$, not switches. The state evolves as an explicit leaky
difference equation:

$$s(t+1) = \lambda\, s(t) \;+\; W_{in}^\top x \;+\; g\, W_{lat}^\top s(t)$$

followed by an intensity-dependent phase shift (the optical Kerr effect,
$\theta \mathrel{+}= \chi |A|^2$) and an energy regulator. Readout is the summed
$|s|^2$ over each class's block of neurons.

**3. Local Hebbian learning, no gradients.** On each sample the target class's
weights rotate their phase toward the **conjugate of the input phase** and grow
in magnitude; on an error, the wrongly-predicted class's weights are kicked in
phase and shrunk. Storing the conjugate is holographic recording — it is what
makes a phase-carrying input add coherently instead of as a random walk — and
with a zero-phase input it reduces exactly to the original "rotate toward zero"
rule.

**4. Global energy homeostasis.** The state's L2 norm is regulated at every
timestep, so neurons compete for a fixed budget. Two honest variants are
implemented and measured, a ceiling clamp and a true normalisation; see
`regulate_energy`.

Multiple prototypes per class and an optional ensemble of columns sit on top.

## What this is not

Stating the limits before a reader has to find them.

- **Not quantum.** Complex amplitudes and interference are classical wave
  physics. An antenna array does interference. The bar for "quantum" is
  superposition over an exponentially large state space plus entanglement, and
  there is no route to either from this architecture. "Quantum-inspired" is a
  real term of art, but it refers to things like tensor-network methods; this is
  not that.
- **Not state of the art on accuracy.** A small MLP beats it, and so does
  logistic regression on this model's *own features*. That gap is the honest
  subject of the ablation table, not something to be explained away.
- **Not one-shot learning.** It is single-epoch **online** learning: one pass,
  batch size 1, no revisiting. That is a real and interesting property. It is
  not one-shot, and the repository previously said it was.
- **Not free of overfitting.** The earlier "Test > Train, zero overfitting"
  claim compared a *running average taken during training* — untrained warm-up
  included — against a test accuracy measured afterwards. Measured properly, with
  a second pass over the training set at plasticity off, train accuracy sits
  above test accuracy, as it does for ordinary models. `bench.py` prints all
  three numbers separately.
- **Not validated against a hardware energy claim.** Nothing here has been run on
  photonic hardware, and no energy measurement backs any efficiency figure. The
  FFT front-end and the phase rotations are natively optical; `W_in^T x` is a
  dense matrix multiply, which on photonic hardware means an MZI mesh — the same
  thing this project's README once criticised competitors for.
- **Not yet demonstrated on few-shot or continual learning.** The
  class-incremental result is the most likely genuine win and is measured in
  `results.md`, but a prediction registered in advance is not a result until the
  table says so.

## Mechanism status

The founding ideas are sound. Several of them were, until recently, not
connected to anything — `W_lat` was identically zero after the first training
sample, the recurrent loop overwrote its own state so `time_steps` of 1 and 99
gave bit-identical predictions, and the front-end discarded all phase before the
cortex saw it.

`tests/test_mechanisms.py` now holds one executable claim per mechanism, so this
class of silent failure cannot come back. A mechanism that is dead is marked
`xfail(strict=True)`: the suite stays green, the marker is a precise statement of
what is broken, and the moment a repair lands the test passes, strict mode turns
that into a failure, and the marker has to be deleted. `ablate.py` then reports
what each live mechanism is actually worth.

Run `python -m pytest` to see the current state, and read `results.md` for the
numbers.

## Reproducing every number

```bash
git clone https://github.com/max-wilson93/quantum-cortex.git
cd quantum-cortex
pip install -r requirements.txt
python download_mnist.py       # the dataset is no longer committed
```

| Command | What it produces |
|---|---|
| `python main.py` | One seeded run; prints online / train / test accuracy separately |
| `python bench.py` | The model against five baselines, 5 seeds → `results.md` |
| `python ablate.py` | Each mechanism switched off in turn, plus a linear-readout control → `results.md` |
| `python ladder.py` | What each Phase 1 repair cost or bought, one rung at a time → `results.md` |
| `python select.py` | Constants chosen on a validation split carved from **train** → `results.md` |
| `python tasks.py` | Translation, noise, blur and class-incremental learning → `results.md` |
| `python -m pytest` | The mechanism invariants |

Add `--preset full` for the complete 60k/10k split, `--seeds ...` to change the
seed list. Every table stamps its own provenance.

## How to read the results

Two rows carry most of the information.

**Logistic regression on the Fourier features.** It shares the model's
front-end and replaces everything after it with a single matrix. The gap between
that row and the full model is what the cortex contributes — in whichever
direction it points.

**"Identical output" in the ablation table.** An ablation that changes not one
prediction out of thousands has not found a weak mechanism; it has found a
disconnected one. That column is what this harness was built to expose.

Decision criteria were fixed in advance, before any of these numbers existed, in
[`PREREGISTRATION.md`](PREREGISTRATION.md): a mechanism earns its place only with
a paired 95% confidence interval excluding zero, an effect of at least half a
point, and a sign matching a prediction recorded beforehand. A mechanism that
fails is deleted from the code and from this README rather than tuned until it
looks useful.

## Layout

| File | Role |
|---|---|
| `fourier_optics.py` | The spectral front-end. The strong part; treat with care. |
| `quantum_cortex.py` | One cortical column: dynamics, readout, local learning |
| `experiment.py` | `ModelConfig` and the single train/evaluate loop everything shares |
| `data.py` | Seeded splits and feature extraction |
| `baselines.py` | The controls |
| `bench.py`, `ablate.py`, `ladder.py`, `select.py`, `tasks.py` | The measurements |
| `report.py` | Writes `results.md`; no number is typed by hand |
| `tests/` | One executable claim per mechanism |
| `ROADMAP.md` | Where this is going and why |
| `PREREGISTRATION.md` | Decision criteria, fixed before the numbers |

`ModelConfig.legacy()` reproduces the architecture exactly as it stood before
the repairs, so every "before" number is regenerable rather than remembered.

## Where this is going

The closest existing research family is **diffractive deep neural networks**
(D²NN) — passive diffractive layers performing all-optical classification — and
the Fourier front-end sits naturally inside it. The one legitimately quantum
thread is **quantum-limited optical inference**: at very low photon counts an
optical network's accuracy ceiling is set by shot noise rather than by classical
noise, which is an experimentally grounded claim and a genuine low-power edge
argument. Whether a phase-coded architecture degrades more gracefully there than
an amplitude-coded one is a question this repository can begin to answer in
simulation. See [`ROADMAP.md`](ROADMAP.md).
